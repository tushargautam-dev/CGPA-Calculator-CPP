# CGPA-Calculator-C++
🎓 CGPA Calculator (C++)

A menu-driven CGPA Calculator developed in C++ that helps students calculate their Semester GPA (SGPA) and Overall CGPA based on course grades and credit hours. The project is simple, user-friendly, and designed using Object-Oriented Programming (OOP) concepts.

📌 Features

- Menu-driven interface
- Calculate Semester GPA (SGPA)
- Calculate Overall CGPA
- Input multiple courses
- Accept course name, grade point, and credit hours
- Display individual course details
- Calculate total credits and total grade points
- Clean and easy-to-understand code
- Beginner-friendly implementation

🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Arrays
- Functions
- Loops
- Switch Case
- Standard Input/Output
- iomanip Library

📋 How It Works

1. Run the program.
2. Select Calculate Semester GPA from the menu.
3. Enter the number of courses.
4. Enter the course name, grade point, and credit hours for each course.
5. The program calculates and displays:
   - Individual course details
   - Total credits
   - Semester GPA (SGPA)
6. Select Calculate Overall CGPA.
7. Enter your previous CGPA and previous total credits.
8. The program calculates and displays the Overall CGPA.
